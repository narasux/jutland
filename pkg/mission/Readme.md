# 战斗总结

战役结束或暂停时显示的战报。数据只保存在内存里，返回任务选择或重新挑战时清空，不落盘。

## 功能

- 四个页签：总览、舰艇、飞机、详情。
- 总览：双方舰艇/飞机损失、吨位、伤害、战损交换比、舰艇保存率、资金。
- 舰艇/飞机：按舰级/机型统计初始、建造、损失、在役；舰艇显示舰种图标，我方绿色、敌方蓝色。
- 详情：按时间倒序记录击沉、击落、命中、损失、随舰损失。
  - 显示攻击者/目标类型和名称、武器与精确口径、伤害。
  - “击沉”“击落”单独标红。
  - 支持“全部 / 击杀”筛选。
  - 滚轮或拖动滚动条查看更早记录；单页优先显示 13 个舰级。
- 所有文案支持中/英/日/俄。

## 实现

- 统计数据：`state/battle_stats.go`
  - `BattleStats` 按玩家保存双方战果，只在事件点累计，不在结算时扫描战场。
  - 战报关闭时由 `ClearBattleStats` 统一重置。
- 战况日志：`state/battle_log.go`
  - `BattleLogEntry` 保存时间、攻击者、目标、动作、伤害、武器和口径。
  - 连续同类命中在 60 tick 内合并，最多保留 50000 条。
- 事件接入：`manager/battle_log.go`、`manager/combat.go`
  - `hurtShip` / `hurtPlane` 记录非致命命中和最终击杀。
  - 开火时把攻击者名称/类型快照进子弹，避免攻击者先消失后日志找不到人。
  - 口径从弹药配置名解析，例如 `JP/GB/7.7/1922` 显示 `7.7mm`。
- 绘制：`drawer/report.go`、`report_pages.go`、`report_events.go`
  - 用 1280×760 设计尺寸整体缩放。
  - 舰艇明细行前绘制缩略地图同款舰种图标。
  - 详情页的筛选、滚动条和拖动共用同一套布局几何。
- 输入：`game/mission.go`、`manager/status.go`
  - 结算页和暂停战报都支持页签、筛选、滚轮和滚动条拖动。
- 生命周期：`manager/manager.go`、`manager/battle_log.go`
  - 结算时固定统计快照。
  - 开始新任务、返回或重试时清空战报数据并重置页签/滚动/筛选。
